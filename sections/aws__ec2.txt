AWS  EC2 Instances

Creating EC2 Instances via CLI


Basic EC2 Creation (External/Jump Host)

## Instance 1, external

aws ec2 create-security-group --group-name "jump" --description "jump_into_vpc" --vpc-id "vpc-0107b56edb21569e0"
aws ec2 authorize-security-group-ingress --group-id "sg-preview-1" --ip-permissions '{"IpProtocol":"tcp","FromPort":22,"ToPort":22,"IpRanges":[{"CidrIp":"76.23.112.35/32"}]}'
aws ec2 run-instances --image-id "ami-06c8f2ec674c67112" --instance-type "t2.micro" --key-name "leam_sol_arch" --network-interfaces '{"SubnetId":"subnet-03488ee2fbfee919e","AssociatePublicIpAddress":true,"DeviceIndex":0,"Groups":["sg-preview-1"]}' --credit-specification '{"CpuCredits":"standard"}' --tag-specifications '{"ResourceType":"instance","Tags":[{"Key":"Name","Value":"jump_002"}]}' --metadata-options '{"HttpEndpoint":"enabled","HttpPutResponseHopLimit":2,"HttpTokens":"required"}' --private-dns-name-options '{"HostnameType":"ip-name","EnableResourceNameDnsARecord":false,"EnableResourceNameDnsAAAARecord":false}' --count "1"

Troubleshooting EC2 Creation

### A few different options, need to check the defaults.

aws ec2 create-security-group --group-name "jump_access" --description "jump access into vpc." --vpc-id "vpc-081f4e06744552e2a"
aws ec2 authorize-security-group-ingress --group-id "sg-preview-1" --ip-permissions '{"IpProtocol":"tcp","FromPort":22,"ToPort":22,"IpRanges":[{"CidrIp":"76.23.112.35/32","Description":"SSH from My IP"}]}'
aws ec2 run-instances --image-id "ami-06c8f2ec674c67112" --instance-type "t2.micro" --instance-initiated-shutdown-behavior "terminate" --key-name "leam_sol_arch" --network-interfaces '{"SubnetId":"subnet-0b49aca7eed4ef45e","AssociatePublicIpAddress":true,"DeviceIndex":0,"Groups":["sg-preview-1"]}' --hibernation-options '{"Configured":false}' --monitoring '{"Enabled":false}' --credit-specification '{"CpuCredits":"standard"}' --tag-specifications '{"ResourceType":"instance","Tags":[{"Key":"Name","Value":"jump_001"}]}' --metadata-options '{"HttpEndpoint":"enabled","HttpPutResponseHopLimit":2,"HttpTokens":"required"}' --private-dns-name-options '{"HostnameType":"ip-name","EnableResourceNameDnsARecord":false,"EnableResourceNameDnsAAAARecord":false}' --maintenance-options '{"AutoRecovery":"disabled"}' --count "1"
