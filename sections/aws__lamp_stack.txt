Cloud-init User Data Script

#!/bin/bash
dnf upgrade -y
dnf install -y httpd wget php-fpm php-mysqli php-json php php-devel
dnf install -y mariadb105-server
echo "<?php phpinfo(); ?>" > /var/www/html/phpinfo.php
usermod -a -G apache ec2-user
chown -R ec2-user:apache /var/www
chmod 2775 /var/www && find /var/www -type d -exec chmod 2775 {} \;
find /var/www -type f -exec chmod 0664 {} \;
systemctl start httpd
systemctl enable httpd
systemctl start mariadb


Post-launch configuration (on the host)

sudo mysql_secure_installation
systemctl enable mariadb


Security Group Configuration

If there is no inbound rule to allow HTTP (port 80) connections, you must add the rule now. Choose the link for the security group. Add a new inbound security rule with the following values:
    Type: HTTP
    Protocol: TCP
    Port Range: 80
    Source: Custom
